# Hybrid Payment Fraud Detection System

## Overview
This project implements a hybrid payment fraud detection system using
rule-based risk scoring and machine learning (Random Forest).

The system is designed for fintech and banking use cases and supports
CSV/Excel data ingestion, device fingerprinting, real-time fraud alerts,
and dashboard-ready outputs.

---

## Features
- Hybrid fraud detection (Rules + ML)
- Device fingerprinting and behavioral analysis
- Machine learning model training and evaluation
- Real-time fraud alert simulation
- CSV / Excel data support
- Explainable risk scoring

---

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib (for dashboards)
- Google Colab compatible
